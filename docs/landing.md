A store for public, permanent documents that other sites can treat as capability rather than as content to copy.

A bootpage is not a web page. It describes an experience — what parts it has, what each one requires, where its data comes from, and what its author would prefer it to look like. It carries no code, no secrets, and no per-viewer state. A site that receives one decides what to do with it, for whoever is asking.

The point is that you publish once, and every site consuming the page changes with it: no server code touched, nothing redeployed, no file shipped.

Pages here are permanent. An address, once issued, is never reassigned — it is what consumers pin, embed and cite.
